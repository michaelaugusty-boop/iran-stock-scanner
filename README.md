# اسکنر پژوهشی بورس ایران — نسخه اولیه

## اجرای سریع
```bash
pip install -r requirements.txt
streamlit run app.py
```

## قالب CSV
ستون‌های لازم:
`date,symbol,open,high,low,close,volume`

برای هر نماد دست‌کم ۳۰ ردیف روزانه لازم است. تاریخ باید قابل‌خواندن توسط pandas باشد.

## استقرار روی سرور
پس از تهیه VPS دارای Python یا Docker:
```bash
docker build -t iran-stock-scanner .
docker run -d --restart unless-stopped -p 8501:8501 --name iran-stock-scanner iran-stock-scanner
```
برای انتشار عمومی، HTTPS، دامنه و احراز هویت را با reverse proxy مانند Caddy یا Nginx تنظیم کنید. پورت برنامه را بدون محافظت روی اینترنت باز نگذارید.

## محدودیت‌های نسخه فعلی
- داده نمونه ساختگی است و داده زنده بورس نیست.
- برنامه در حال حاضر به TSETMC یا ایزی‌تریدر متصل نیست.
- ورود داده از طریق CSV انجام می‌شود.
- امتیاز ۰ تا ۱۰۰ یک فیلتر تکنیکالی آزمایشی است، نه توصیه خرید یا پیش‌بینی سود.
- حمایت/مقاومت با کمینه/بیشینه ۲۰ جلسه اخیر تخمین زده می‌شود.
- تشخیص پولبک، بک‌تست، تعدیل قیمت و فیلتر نقدشوندگی باید در مراحل بعدی اضافه شوند.

## مرحله بعد
برای اتصال داده خودکار باید منبع داده و شرایط استفاده از API آن بررسی شود. رمز حساب ایزی‌تریدر را در برنامه یا چت وارد نکنید.
